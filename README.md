
# Health Article Simplifier

## Project Overview
Health Article Simplifier is a Python-based application
that converts complicated health information into
simple and understandable language.

## Technologies
- Python
- Streamlit
- Regular Expressions

## Features
1. Enter health articles.
2. Simplify medical terminology.
3. Choose reading levels.
4. Explain medical terms.
5. Download simplified articles.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Purpose
To make health information easier for general readers.

## Disclaimer
This application is for educational purposes only.
It does not provide medical advice.
